# Painel de DP & RH

Dashboard standalone em HTML/JS com indicadores de gestão de pessoas, construído como peça de portfólio.

## Funcionalidades

- **Visão Geral**: headcount, admissões/desligamentos do mês, turnover médio (12 meses), absenteísmo, evolução de headcount e distribuição por departamento
- **Calculadora de Rescisão**: saldo de salário, 13º e férias proporcionais, férias vencidas, aviso prévio e multa do FGTS (regras gerais da CLT)
- **Ponto & Banco de Horas**: saldo de horas por colaborador com status (positivo/negativo/em dia)
- **Férias & Movimentação**: próximas férias e histórico de admissões/desligamentos

## Tecnologias

HTML, CSS, JavaScript, Chart.js

## Observação

Projeto de portfólio pessoal, com dados **fictícios** gerados apenas para demonstração. Os cálculos de rescisão são simplificados e não substituem o sistema oficial de folha de pagamento.
